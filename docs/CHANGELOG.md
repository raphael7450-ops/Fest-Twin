# Fest-Twin 변경 내역 (CHANGELOG)

Fest-Twin 디지털 트윈 기반 축제 기획·인파 안전 통합 시뮬레이션 플랫폼의 버전별 변경 내역입니다.

## [v2.3.0] - 2026-08-19

### 체류시간 및 동시 체류 수용성 모델 구현
- 체류 프로필 엔진 구축 (src/services/visitorOccupancy.ts)
  - 축제 유형별 기본 체류시간(120~270분) 및 이탈 감소율 프로필 적용
  - 불꽃 축제형 Anchor 연동 및 이탈 지연 처리
  - 시간대 신규 유입(arrivals)과 동시 체류인원(occupancy) 분리
- 인프라 및 안전 산출식 체류 기반 전환
  - 인파 밀집도, 대피 시간, 주차 차오름, 임시 화장실 수요 계산 시 최대 동시 체류인원 적용
  - 쓰레기 배출량 및 지역 상권 경제 파급효과는 일일 고유 방문객 기준 유지
- 기획안 체류·시설 입력 및 시나리오 연동
  - 기획안 입력 폼에 평균 체류시간, 주차 수용 대수, 화장실 변기 수 입력 필드 추가
  - TourAPI 축제 변경 시 오버라이드 자동 초기화 및 시나리오 정규화 지원
- 수요 예측 차트 및 수용성 패널 UI 개선
  - 수요 예측 차트에 동시 체류 / 신규 유입 선택 탭 구현
  - 인프라 수용성 패널에 기획 입력 필요 상태 및 최대 이탈 시간대 표시
- 공공 검토 근거, CSV, 결재 보고서 갱신
  - 산출 근거 및 B2G 결재 보고서, CSV 내보내기에 일일 고유 방문객, 최대 동시 체류인원, 체류 프로필, 최대 이탈 정보 통합
- 보고서 증빙 일관성 및 테스트 보정
  - 화면 보고서와 B2G 인쇄본에 체류 프로필 출처, 평균 체류시간, 동시 체류 피크, 피크 이탈 정보를 동일하게 표기
  - 행사장 면적 미입력 상태를 검증하는 테스트 픽스처가 명시적으로 면적을 제거하도록 보정

## [v2.2.0] - 2026-08-07

### 신규 기능 및 데이터 파이프라인 확장
- 전국 대표 축제 검색 데이터베이스 연동 확장
  - server/db/regionalFestivalDatabase.js 및 /api/regional-festivals 엔드포인트에 전국 5,700여 건 공공축제 DB 연동 완료
  - 키워드, 지역, 기간 필터링 및 검색 지원
- 축제 베이스 키 정규화 및 중복 데이터 제거
  - 연도(2022~2026년) 및 회차(제XX회) 접두어를 정규화하여 동일 축제의 중복 카드 표출 방지
  - 기준 축제당 가장 최신 연도의 데이터만 단일 표출하도록 자동 중복 제거 적용
- 지역 맞춤형 주변 관광지 보강 데이터 생성 엔진
  - TourAPI 주변 관광지 조회 결과 미반환 시 고정 서울(코엑스, 봉은사 등) 데이터 대신 선택된 축제 지역(논산, 보령, 부산, 진주, 대전, 세종, 전주, 화천, 안동, 제주, 수원, 인천, 광주, 대구, 울산 등 16개 지역)에 일치하는 맞춤형 대표 관광지 보강 데이터 자동 매핑

### 검색 및 상태 반응성 보완
- 엄격한 지역 필터링 강제
  - server/db/regionalFestivalDatabase.js 및 src/services/tourApiAdapter.ts에서 개최 지역 선택 시 키워드 검색 시에도 다른 지역 축제가 혼입되지 않도록 지역 매칭 우회 방지 적용

  - 축제 변경 시 입력 파라미터, 4단계 예측 수식, Metric Evidence Drawer, CSV 내보내기 데이터의 100% 즉시 갱신 및 이머징 잔재 데이터 비존재 증빙
  - 연속 빠른 축제 전환(A -> B -> C -> A) 시 비동기 직렬화 키 보장 검증

### 테스트 및 안정성 검증

## [v2.1.0] - 2026-08-05

### 주요 기능 개선 및 보안 강화
- 선택 축제 기본 정보 카드 (SelectedFestivalCard) 구현
  - TourAPI 4.0 기반 대표 이미지, 주최/주관, 운영시간, 개최 기간, 주소를 대시보드 상단 카드로 표출
- 시나리오 A/B 병렬 비교 모드
  - 2개 시나리오 체크박스 선택 후 Side-by-Side 수용 인원/예산/시설 diff 비교 팝업 제공
- LRU 캐시 Eviction 및 Audit Log 비동기 저장
  - server/cache.js 인메모리 캐시 최대 1,000개 슬롯, O(1) LRU 순서 갱신 구현
  - setImmediate + fs.createWriteStream 비동기 감사 로그 영구 파일 저장
- 공개 API 5종 추가 연동
  - 기상청 단기예보 (/api/weather): 강수확률/기온/풍속 수요 보정계수 적용
  - TAGO 대중교통 (/api/transit/nearby-stops): 버스정류소/노선 정보
  - 소상공인 상가정보 (/api/commercial/nearby-stores): 행사장 반경 상권 밀도
  - 응급의료기관/119 (/api/emergency/nearby-facilities): 응급기관 위치 정보
  - 네이버 데이터랩 이중 엔드포인트 자동 전환 지원
