## 1. 개인정보 미수집 (0건) 처리 기본 원칙

Fest-Twin 서비스는 공공 축제 사전 검토 및 디지털 트윈 시뮬레이션을 제공하는 B2G 분석 웹 시스템으로서, **사용자(공무원/축제기획자/일반인)의 개인정보를 일절 수집하거나 저장하지 않습니다.**

```
[사용자 접속] ──▶ [로그인 불필요 (무개정 익명 접속)] ──▶ [시나리오 시뮬레이션 및 익스포트]
                           │
                           ▼
                 [개인정보 수집 항목: 0건]
```

## 3. 로그 파일 개인정보 마스킹 방침

1. **Express 서버 액세스 로그 (`server/logger.js`)**
   - 사용자 IP 주소는 DDoS 및 Rate Limit 429 감시용으로만 수신되며, 로그 파일 기록 시 일부 식별자를 비식별 마스킹 처리할 수 있습니다.
2. **시나리오 저장소 (`data/scenarios_db.json`)**
   - 시나리오 데이터 내에는 작성자의 개인정보가 포함되지 않으며, 시나리오 ID(`scen_*`) 및 공유 토큰(`tok_*`)으로만 관리됩니다.
