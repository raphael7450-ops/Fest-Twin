# Fest-Twin 기능 설명

## 서비스명

Fest-Twin

## 서비스 유형

공공데이터 기반 B2G 축제 기획 사전 진단 웹 서비스

## 대상 사용자

- 지자체 축제 기획 담당자
- 지자체 안전관리 부서
- 지역경제·관광 활성화 담당 부서
- 공모전 심사위원 및 공공 사업 평가 담당자

## 서비스 개요

Fest-Twin은 축제 개최 전 수요 예측 실패, 경험 의존형 예산 편성, 대규모 관광객 쏠림에 따른 만족도 저하와 안전 리스크를 줄이기 위한 사전 진단 서비스다. 사용자가 지역, 기간, 예산, 수용 인원, 프로그램 정보를 입력하면 한국관광공사 TourAPI 축제 후보와 주변 관광지 데이터를 기반으로 수요 예측, 혼잡도 시뮬레이션, 안전·물류 권고, 예산 대비 경제효과를 산출한다.

## 주요 기능

1. 지역·기간 기반 TourAPI 축제 후보 조회
2. 선택 축제 기준 기획안 자동 채움
3. 예상 방문객, 흥행 예측 지수, ROI, 안전·물류 KPI 산출
4. Naver DataLab 검색량 기반 사전 관심도 보정
5. KTDB/View-T 교통 근거와 관광소비 객단가 반영
6. 행사장 지도와 혼잡도 히트맵 시뮬레이션
7. KPI별 산출 근거 Drawer 제공
8. 시나리오 저장 및 공유 링크 복원
9. 공공검토 보고서 출력

## 공공검토 보고서

보고서는 단순한 대시보드 캡처가 아니라 지자체 내부 검토와 부서 협의를 위한 사전 검토 문서로 구성한다.

포함 섹션:

- 예측 결과: 예상 방문객, 피크 시간, 성공 예측 점수
- 혼잡·안전 진단: 위험 점수, 병목 가능성, 주요 findings
- 예산·경제 효과: 총 투입 예산, 관광소비 객단가, ROI
- 사용 데이터와 한계: TourAPI, 검색 트렌드, KTDB/View-T, 소비 데이터, fallback 상태
- 개선 권고: 프로그램 분산, 안전 인력, 동선 보완 등 부서 협의 항목

보고서에는 선택한 TourAPI 축제 `contentId`, 활용 어플 URL, OpenAPI 호출 흐름, 출처 및 라이선스 표기를 함께 표시한다. API 키, client secret, Authorization 헤더, Cookie 같은 비밀값은 보고서와 브라우저 번들에 노출하지 않는다.

## 데이터 해석 한계

TourAPI는 축제 메타데이터와 관광지 정보를 제공하지만 축제별 실제 방문객 집계값을 항상 제공하지 않는다. 따라서 Fest-Twin의 예상 방문객 수는 TourAPI 메타데이터, 유사 축제·지역 백데이터, 검색 관심도, 사용자가 입력한 예산·수용 인원·프로그램 정보를 결합한 사전 의사결정용 추정값이다.

Naver DataLab 검색량은 실제 방문객 수가 아니라 개최 전 관심도 흐름을 나타내는 보조 지표다. 서비스는 이 값을 방문객 수로 직접 치환하지 않고 제한된 보정 계수로 사용한다.

## Fallback 정책

외부 API 키가 없거나 호출이 실패해도 서비스 화면은 중단되지 않는다. 이 경우 검증 스냅샷 또는 샘플 데이터를 사용하며, 화면과 보고서에 실데이터, 부분 보완, 파일 정규화, 샘플 보완 상태를 명확히 표시한다.

## 제출 제외 범위

Instagram Hashtag API와 X API 실시간 연동은 권한 심사와 비용 리스크가 있어 2026년 9월 제출 버전에는 완료 기능으로 포함하지 않는다. 해당 채널은 v2.0 확장 예정 기능으로 문서화한다.
