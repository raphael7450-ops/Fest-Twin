Fest-Twin은 지자체 문화관광·안전 담당자 및 B2G 사업 평가위원을 대상으로, 축제·행사 기획 단계에서 발생하는 불확실한 방문객 추정과 예산 근거 부재 문제를 실공공데이터 기반 디지털 트윈으로 해결하는 플랫폼입니다.

본 자료는 핵심 기술 아키텍처, 수치 산출 근거 시각화, 부서 간 협업 파이프라인, 그리고 미래 확장 로드맵을 포함한 종합 사업 제안서입니다.

### 발표자 정보 & 타겟
- **발표자**: Fest-Twin 개발팀
- **대상**: B2G 사업 평가위원 및 지자체 문화관광/안전 담당자

## 2페이지: 1. 기존 행사 기획의 한계와 행정적 페인포인트

> "이 축제에 예산 5억 원을 투입하면, 방문객은 정말 5만 명이 오나요?"

### 1) 과거 경험과 감(感) 위주의 추정
- 근거가 불명확한 관행적 방문객 및 경제 효과 부풀리기
- 감사(Audit) 및 수의계약 검증 시 객관적 입증 자료 부재
- 담당자 개인 경험에 의존한 비재현적 기획 프로세스

### 2) 실시간 통신사 데이터의 한계
- 행사 당일 사후 인파 추정은 가능하나, 사전 기획/예산 수립 단계의 예측 불가능
- 좁은 현장 밀집도 오차 발생
- 수백만 원 대의 높은 수집 비용 발생

### 3) 부서 간 파편화된 시나리오 관리
- 담당자 변경 시 이전 기획 데이터 및 수치 산출 기준 분실
- 부서 간 시나리오 공유 체계 부재
- 상급 기관 보고 시 일관된 근거 자료 제출 불가

> **주의**: 현행 행사 기획 프로세스는 감사 대응, 예산 투명성, 부서 연속성 세 가지 측면 모두에서 구조적 취약점을 내포하고 있습니다.

## 3페이지: 2. Fest-Twin 핵심 솔루션 & B2G 가치

> 사전 예측의 신뢰성과 행정 투명성을 극대화한 디지털 트윈

### 1) 실공공데이터 기반 정밀 수요 예측
- **한국관광공사 TourAPI 4.0 + 국가교통DB(KTDB) 도로 링크 교통량 기준선 연동**
- API 장애 시 정규화 백데이터 기반 **Graceful Fallback 자동 전환**으로 서비스 연속성 100% 보장
- 공공 인증 데이터 소스 활용으로 **감사 대응 근거 확보**

- 수식(Formula), 가중치 계수, 출처 라벨을 투명하게 공개
- **Metric Evidence Drawer**를 통한 단계별 연산 흐름 추적
- **감사 대응 완료** — 행정적 근거 완벽 입증 가능

### 3) 시나리오 영속 저장 및 URL 즉시 공유
- **영속 REST API & LocalStorage 하이브리드 스토리지 기반 share_token 생성**
- 타 부서 및 상급 기관 즉시 복원 협업 가능
- 시크릿 탭/타 부서 PC 접속 시에도 동일 시뮬레이션 환경 100% 재현

## 5페이지: 4. 수치 산출 근거 시각화 (Metric Evidence Drawer)

> 1단계 베이스라인부터 4단계 최종 산출까지 연산 흐름 투명 공개

### 4단계 연산 흐름 (4-Step Breakdown)
1. **Step 1 베이스라인 추출**: TourAPI 4.0 주변 관광지 매력도 및 KTDB 정체 지수 정규화
2. **Step 2 매력도 및 규모 가중**: 개최 시기, 예산 규모, 시간대별 특성별 계수 배치(Badge) 부여
3. **Step 3 상권 및 트렌드 보정**: 관광데이터랩 카드 소비 객단가 기반 경제 파급효과 계산
4. **Step 4 최종 추정치 산출**: 예상 방문객(명), 밀집도(명/m²), ROI 파급효과(배) 콤마 포맷팅 출력

### 핵심 수식 (Formulas)
```text
Step 1: Base_Visitors = Area_m² × Target_Density
Step 2: Weighted_Visitors = Base_Visitors × Budget_Weight(1.15x) × Time_Weight(1.08x)
Step 4: Final_Output = { 방문객 추정치(명), 밀집도(명/m²), ROI 파급효과(배) }
```

### 계수 및 출처 투명성
| 계수 | 값 | 출처 |
| :--- | :--- | :--- |
| Budget_Weight | 1.15x | KTDB 2026 / 예산 가중 |
| Time_Weight | 1.08x | TourAPI 4.0 / 시간대 보정 |
| Target_Density | 입력값 | 행사 기획서 |
| 경제 파급 계수 | 객단가 기반 | 관광데이터랩 카드 소비 |

## 7페이지: 6. 결론 및 질의응답 (Q&A)

> 행정의 신뢰성을 높이는 B2G 표준 사전 진단 플랫폼

> "Fest-Twin은 불확실한 행정 예측을 데이터 중심의 투명한 의사결정으로 바꿉니다."

### 주요 질의응답 (Q&A)
- **Q1. 공공 API 서버 장애 발생 시 서비스가 중단되나요?**
  - **답변**: 아니오. 정규화된 공공 백데이터 모드로 자동 전환되어 서비스 연속성을 **100% 보장**합니다. Graceful Fallback 메커니즘이 API 장애를 감지하는 즉시 백데이터 기반 운영으로 전환됩니다.
- **Q2. 수치 산출 근거를 감사 기관에 증빙할 수 있나요?**
  - **답변**: 네. Metric Evidence Drawer의 수식, 계수, 출처 데이터를 통해 행정적 근거를 완벽히 입증할 수 있습니다. 4단계 연산 흐름 전체가 투명하게 공개되어 감사 대응에 즉시 활용 가능합니다.
- **Q3. 동시 접속자가 몰려도 서버가 안전한가요?**
  - **답변**: 네. 2단계 Rate Limiter 방어 기작(일반 API 300회/분, 외부 OpenAPI 120회/분)과 1.81ms 캐시 응답 속도로 대규모 부하를 안정적으로 수용합니다. 로컬 격리 테스트 기준 571.27 TPS 처리 성능이 검증되어 있습니다.

### 핵심 가치 요약
- **투명성**: 4단계 산출 근거 완전 공개
- **연속성**: Fallback + share_token 영속 협업
- **성능**: 571.27 TPS · 1.81ms · 115테스트 PASS
