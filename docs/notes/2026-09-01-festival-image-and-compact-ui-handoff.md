## 새로 확인된 문제

선택 전 후보 이미지와 선택 후 카드 이미지 URL은 동일하게 유지된다.

운영 화면에서 확인한 예:

- 후보: `2026 서울국제정원박람회`
- 후보 이미지: `/festival-images/jinju_yudeung.png`
- 선택 후 이미지: `/festival-images/jinju_yudeung.png`

따라서 선택 과정에서 이미지가 바뀌는 문제가 아니다. 공식 이미지가 없는 후보에 다른 지역 축제 사진을 대체 배정하면서 축제 내용과 사진이 일치하지 않는 것이 실제 원인이다.

## 승인 대기 중인 수정 방향

B2G 운영 도구에서는 그럴듯하지만 잘못된 사진을 표시하지 않는 것을 우선한다.

1. TourAPI `firstimage` 등 공식 이미지가 있으면 그대로 표시한다.
2. 공식 이미지가 없으면 다른 축제 사진을 사용하지 않는다.
3. 축제명과 지역을 포함한 중립 플레이스홀더를 표시한다.
4. 후보 목록과 선택 후 상세 카드가 같은 이미지 상태를 유지한다.
5. 공식 이미지와 플레이스홀더 경로를 자동 테스트로 구분한다.

다음 작업 시작 시 사용자에게 위 방향의 승인을 받은 뒤 TDD로 구현한다.

이 단계에서는 아직 레이아웃 구현이나 최종 디자인을 확정하지 않는다.
