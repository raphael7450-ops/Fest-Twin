# 전년도 기준값과 대체 검증

## 운영 범위

동일 명칭·지역·직전 집계 연도의 공식 보고 수치를 별도 참고 기준값으로 표시한다. 이 기능은 예측 모델 자체를 전년도 수치로 대체하는 기능이 아니다. 집계 방법 미확인 자료는 모델 입력과 정확도 평가에서 계속 제외한다.

`data/prior_year_visitor_references.json`은 기존 수집 원장의 CSV 출처 109행과 순천 26행에서 만든 135행의 별도 참고 목록이다. 행사 연도가 명시된 CSV를 대상으로 하며 개최 계획 파일의 게시 연도를 집계 연도로 바꾸지 않았다. 원천 URL, SHA256, CSV 행 번호를 보존했다. 취소와 알려진 기간 충돌·재검토 대상은 `excluded`로 차단했다. 모든 자료는 `method_unverified`이며 승인된 실적이 아니다.

일치하는 직전 연도 자료가 없으면 확인 불가로 표시한다. 전전년도나 같은 지역 다른 축제, 샘플 수치로 대체하지 않는다. 중복 출처가 나오면 임의 선택하지 않는다. 같은 이름의 행사 식별은 여전히 검토가 필요하며 이 매칭은 공식 행사 ID 인증이 아니다.

## 대체 검증 절차

1. 행사 전 화면의 예측을 기존 서버 보관 흐름으로 저장한다. 이제 `datasets.priorYearReference`도 함께 보관되며 기존 모델 입력 객체는 변경하지 않는다.
2. 올해 측정은 행사 담당자가 출입 계수·입장권 등의 측정 수단, 구역과 기간, 재입장 처리, 운영인력 제외 여부를 기록한다. 실제 계측이나 기관 협조는 아직 실행되지 않았다.
3. 개인정보 없는 집계표와 원본 근거를 검토한 후에만 실적 원장에 승인한다. 누적 출입과 중복 제거 방문객을 혼합하지 않는다.
4. 기존 `visitorReplay` 및 `visitorEvaluation`의 전년도 기준 비교 경로를 이용한다. 같은 축제·기간·지리 범위·측정 단위의 올해 실측에 모델과 전년도 기준 예측을 각각 비교한다. 전년도 입력도 당시 이용 가능성과 집계 방법 검토를 통과해야 한다.
5. 올해 실측이 없거나 계측 범위가 다르면 정확도는 판정하지 않는다. 회귀 재현 결과를 실제 사전 예측 실적으로 부르지 않는다.

보관된 기준값의 해시는 변조 탐지용이지 집계 방식의 정확성을 증명하지 않는다. 공개 수치 자체의 진실성 검증, 새로운 측정 장비 설치, 현장 계수, 자동 실적 승인은 이번 변경에 포함되지 않는다.
