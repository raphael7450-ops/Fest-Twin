# 페스트트윈 공공데이터 및 개인정보 최소수집 정책

## 공공데이터 활용

- 기본 공공데이터 출처는 한국관광공사 TourAPI다.
- MVP는 실제 API 키가 없어도 동일한 화면 흐름을 보여주기 위해 TourAPI 형태의 샘플 데이터를 사용한다.
- 화면과 리포트에는 샘플 데이터 또는 캐시 대체 사용 여부를 표시한다.

## 개인정보 최소수집

MVP는 다음 정보를 수집하지 않는다.

- 담당자 실명
- 휴대전화번호
- 이메일
- 주민등록번호
- 결제정보
- 개인별 위치 이력

## 사용자 입력 데이터

사용자는 축제명, 지역, 기간, 예산, 프로그램, 행사장 배치 등 축제 기획 데이터만 입력한다. 이 데이터는 축제 수요 예측, 혼잡 시뮬레이션, 기획 보완 리포트 생성을 위한 목적에 한정한다.
