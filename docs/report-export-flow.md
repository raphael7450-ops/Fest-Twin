# 페스트트윈 리포트 출력 흐름

## 목적

페스트트윈의 기획 보완 리포트는 지자체 담당자가 축제 예산 집행 전 검토 자료로 출력하거나 PDF로 저장할 수 있어야 한다. MVP에서는 브라우저 기본 인쇄 기능을 사용해 별도 서버 없이 리포트 출력 흐름을 제공한다.

## 사용자 흐름

1. 대시보드에서 축제 기획안, 예산, 예상 수용 인원, 진단 시간대를 확인한다.
2. 화면 하단의 `기획 보완 리포트` 영역으로 이동한다.
3. `리포트 인쇄` 버튼을 선택한다.
4. 브라우저 인쇄 창에서 프린터 출력 또는 PDF 저장을 선택한다.

## 인쇄 범위

인쇄 시에는 심사·보고에 필요한 리포트 영역을 우선 노출한다.

- 기획 보완 요약
- 공공 검토용 설명
- 흥행 가능성, 밀집 위험, 예산 낭비 위험, 만족도 저하 위험 점수
- 기획 보완 권고안

대시보드 조작 영역, 입력 폼, 그래프, 히트맵은 화면 검토용 요소이므로 인쇄 화면에서는 숨긴다.

## 집에서 확인

```powershell
git checkout agent/government-guided-mvp
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:5173/`을 열고 `기획 보완 리포트` 영역의 `리포트 인쇄` 버튼을 선택한다.
