# 페스트트윈 시나리오 저장·불러오기 흐름

## 목적

축제 기획안은 예산, 수용 인원, 시간대에 따라 수요 예측과 혼잡 진단 결과가 달라진다. 시나리오 저장 기능은 지자체 담당자가 여러 기획안을 빠르게 비교하고, 심사 자리에서 변경 전후를 즉시 보여주기 위한 MVP 기능이다.

## 저장 항목

브라우저 로컬 저장소에 다음 항목을 저장한다.

- 축제 기획안 전체
- 총 예산
- 예상 수용 인원
- 선택한 진단 시간대
- 저장 시각

개인정보는 저장하지 않는다.

## 사용자 흐름

1. 축제명, 지역, 예산, 예상 수용 인원 값을 조정한다.
2. 진단 시간대를 선택한다.
3. `시나리오 저장` 버튼을 선택한다.
4. 저장된 시나리오 목록에서 원하는 항목을 선택한다.
5. 대시보드가 저장 당시의 기획안과 시간대로 복원된다.

## 저장 정책

- 저장 위치는 브라우저 `localStorage`다.
- 서버 전송 없이 현재 브라우저에만 저장한다.
- 최근 5개 시나리오만 유지한다.
- `모두 지우기` 버튼으로 저장된 시나리오를 삭제할 수 있다.

## 집에서 확인

```powershell
git checkout main
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:5173/`을 열고 `시나리오 저장` 영역에서 저장과 불러오기를 확인한다.
