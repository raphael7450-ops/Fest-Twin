# 유사 축제 백데이터 신뢰도 기준

Fest-Twin은 TourAPI가 제공하지 않는 실제 방문객·예산 기준을 보완하기 위해 문화체육관광부 지역축제 개최계획 정규화 DB를 사용한다. 이 DB는 수요 예측의 확정값이 아니라, 현재 기획안과 성격이 가까운 과거·예정 축제를 비교하기 위한 기준선이다.

## 매칭 기준

유사 축제는 다음 항목을 함께 평가한다.

1. 지역 일치도: 입력 지역과 DB 축제의 광역·기초 지자체 일치 여부
2. 축제 성격: 카운트다운·새해, 불꽃·야간, 해양·여름, 음식, 음악·공연, 꽃, 전통 등 주제군 일치 여부
3. 개최 시기: 입력 시작일·종료일의 월과 DB 축제 기간의 월 일치 여부, 연말·연초 축제 여부
4. 키워드 일치도: 지역명 자체를 제외한 축제명·유형·기간 키워드 일치 여부
5. 예산 규모: 입력 예산과 DB 축제 예산의 상대적 규모

## 제외 기준

같은 지역이더라도 축제 성격이나 개최 시기가 맞지 않으면 유사 축제 기준에서 제외한다. 예를 들어 `부산 카운트다운 축제`는 연말·새해맞이 성격이 강하므로, 방문객 규모가 큰 `부산 바다축제`가 단순히 같은 지역이라는 이유만으로 근거에 포함되지 않는다.

## 근거 표시

KPI의 `근거 보기`에는 실제 화면 계산에 사용된 유사 축제만 표시한다. 각 레코드는 축제명, 지역, 유형, 기간, 방문객 수, 예산, 원천 파일, 유사도 점수를 함께 제공한다. 원천 파일은 정렬 전 후보 순서가 아니라 최종 선택된 유사 축제 레코드에 직접 연결된 값을 표시한다.

## 해석 한계

방문객 수와 예산은 지자체 또는 원천 파일 기준의 공개 계획·실적성 데이터이며, 현재 기획안의 확정 방문객 수가 아니다. Fest-Twin은 이 값을 TourAPI 메타데이터, 검색 관심도, 교통·소비 근거, 사용자 입력값과 함께 결합해 사전 의사결정용 추정값으로 사용한다.
