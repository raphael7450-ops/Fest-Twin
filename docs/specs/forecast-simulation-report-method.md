# 페스트트윈 수요 예측·혼잡 진단·리포트 산정 기준

## 목적

본 문서는 페스트트윈 MVP가 축제 기획안을 어떻게 데이터 기반으로 진단하는지 공공기관 검토자가 이해할 수 있도록 산정 기준을 정리한다.

## 수요 예측 기준

수요 예측은 다음 항목을 종합한다.

- 실제 TourAPI 또는 대체 샘플의 주변 관광지 매력도
- 유사 축제 메타데이터로 추정한 수요 프록시와 주제 유사도
- 실시간 연동이 아닌 비개인 사전 정의 키워드 관심도 샘플
- 프로그램별 집객력
- 총예산 규모
- 출입구 수와 기본 수용 여건

예측 결과에는 예상 방문객 수, 시간대별 방문객 분포, 피크 시간, 흥행 가능성 점수, 예측 신뢰도를 포함한다.

TourAPI는 유사 축제의 실제 방문객 집계값을 제공하지 않으므로, 앱의 유사 축제 수요 값은 행사 기간, 이미지·개요 유무, 주변 관광정보 수로 계산한 추정 프록시다. 실제 방문객 통계로 해석해서는 안 된다.

예측 신뢰도는 관광·트렌드 레코드 수와 출처 상태를 함께 반영한다. TourAPI 샘플·부분 대체 또는 트렌드 샘플이 포함된 예측은 레코드 수가 많아도 `high`가 될 수 없고 최대 `medium`으로 제한된다.

## 혼잡 진단 기준

행사장은 격자 기반 공간으로 단순화한다. 각 격자는 방문객 규모, 시설물 위치, 시설별 유인 가중치, 피크 프로그램 집객력을 반영해 밀집도를 계산한다.

밀집도 단계는 다음과 같이 구분한다.

| 밀집도 | 단계 |
| --- | --- |
| 0~29 | low |
| 30~59 | medium |
| 60~84 | high |
| 85~100 | critical |

high 이상 격자는 병목 후보로 분류하며, 밀집도가 높은 순서로 주요 병목 지점을 제시한다.

## 리포트 산정 기준

기획 보완 리포트는 다음 위험 점수를 생성한다.

- 흥행 가능성
- 밀집 위험
- 예산 낭비 위험
- 만족도 저하 위험

리포트는 점수만 제시하지 않고, 공공기관 실무자가 조정 가능한 개선 권고를 함께 제공한다. MVP 권고안은 피크 프로그램 분산, 출입구 안내 인력 재배치, 먹거리 부스 동선 분리, 주변 관광지 연계 코스 운영을 포함한다.

## 개인정보 처리 원칙

본 산정 로직은 개인 식별 정보, 개인별 위치 이력을 사용하지 않는다. 현재 MVP의 소셜 트렌드는 실시간 외부 연동 없이 키워드 단위의 비개인 관심도 샘플로만 표현한다.
