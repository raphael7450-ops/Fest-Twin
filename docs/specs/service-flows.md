# Fest-Twin 서비스 아키텍처 및 주요 작업 흐름 (Service Flows)

본 문서는 Fest-Twin MVP의 대시보드 과업 흐름, 시나리오 저장/복원, 기획 보완 리포트 인쇄, 공개 데모 Tailscale Funnel 운영 흐름을 종합 정리한 문서입니다.

---

## 1. 대시보드 과업 흐름 (Dashboard Service Flow)

### 목적
대시보드는 일반 사용자용 랜딩 페이지가 아닌 지자체 담당자 및 심사위원이 축제 기획안을 다각도로 진단하는 행정 업무형 대시보드입니다.

### 주요 업무 흐름
1. 축제 기획안 입력: 축제명, 개최 지역, 총예산, 예상 수용 인원을 설정 (담당자 실명/연락처 등 개인정보 미수집).
2. 데이터 근거 확인: 한국관광공사 TourAPI 연동 상태 확인 (API 키 미설정/실패 시 정제된 샘플 데이터 대체 안내 표시).
3. 수요 예측 확인: 예상 방문객 수, 피크 시간대, 시간대별 방문객 분포 확인.
4. 혼잡도 시뮬레이션: 선택 시간대 기준 행사장 격자별 밀집도 및 병목 후보지 진단.
5. 기획 보완 리포트: 흥행 가능성, 밀집 위험, 예산 낭비 위험, 만족도 저하 위험 점수화 및 피크 프로그램 분산/안내 인력 재배치 등 실효성 있는 개선 권고안 제시.

## 2. 시나리오 저장 및 불러오기 흐름 (Scenario Save & Restore Flow)

### 목적
예산, 수용 인원, 시간대 변경에 따른 수요 예측 및 혼잡 위험 결과를 다각도로 시뮬레이션하고 빠르게 비교할 수 있도록 제공하는 MVP 기능입니다.

### 주요 동작 방식
- 저장 위치: 브라우저 `localStorage` (서버로 개인 데이터 전송 안 함).
- 저장 데이터: 축제 기획안 전체, 총예산, 수용 인원, 선택 시간대, 저장 시각 (최근 5개 유지).
- 복원 흐름: 저장된 시나리오 목록 클릭 시 대시보드가 당시 기획안 상태로 즉시 복원됨.

## 3. 기획 보완 리포트 인쇄 및 PDF 저장 흐름 (Report Export Flow)

### 목적
축제 예산 집행 전 지자체 보고용 검토 자료로 출력하거나 PDF 파일로 저장할 수 있는 기능입니다.

### 인쇄 구성 범위
- 인쇄 포함 영역: 기획 보완 요약, 공공 검토용 설명, 4대 위험/흥행 점수, 실행 권고안.
- 인쇄 제외 영역: 조작 컨트롤, 입력 폼, 동적 그래프/히트맵 등 화면 검토 전용 UI 요소.
- 실행 방법: 리포트 영역 하단의 `리포트 인쇄` 버튼 클릭 후 브라우저 인쇄 창에서 프린터 출력 또는 'PDF로 저장' 선택.
