# TourAPI 및 확장 빅데이터 연동 축제 예시

## 목적

기본 데모 축제가 임의 샘플처럼 보이지 않도록, 공개 데모의 TourAPI 프록시에서 실제 조회되는 최근 축제와 확장 빅데이터(관광데이터랩, ITS, 기상청 등)를 기준 예시로 사용한다.

## 조회 조건

- 조회일: 2026-07-20
- 프록시: `https://cwserver.tail97dbc3.ts.net/api/tour/festivals`
- 조건: `areaCode=1`, `eventStartDate=20260101`, `eventEndDate=20261231`, `numOfRows=10`, `arrange=A`
- 비밀값 처리: 브라우저와 문서에는 TourAPI 인증키를 기록하지 않고, 서버 프록시가 런타임 환경변수로만 처리한다.

## 확인된 축제

| 항목 | 값 |
| --- | --- |
| 축제명 | 강남 미디어 윈터페스타 |
| TourAPI contentid | `3439947` |
| 기간 | 2025-12-19 ~ 2026-01-03 |
| 주소 | 서울특별시 강남구 영동대로 511 (삼성동) |
| 연락처 | 02-6000-0114 |
| 좌표 | 127.0610512042, 37.5103955843 |

같은 조회에서 `서울라이트 광화문`도 함께 확인되며, 샘플 관광 맥락의 유사 축제 예시로 함께 둔다.

## 확장 빅데이터 연동 예시 근거

1. 관광데이터랩 유동인구/소비: 강남구 삼성동 겨울철 일일 평균 유동인구 18.5만 명, 음식점/쇼핑 평균 소비 단가 반영
2. ITS 영동대로 소통 정보: 영동대로 구간 평균 통행속도 (18~24km/h 서행 구간 적용)
3. 기상청 강남구 동네예보: 겨울철 평균 기온 -2°C ~ 4°C, 야간 참착률 가감계수(0.92) 적용
4. 행정안전부 안전 매뉴얼: 삼성동 코엑스 야외 광장 m²당 3명 관리 인원 및 의료부스 4개소 권고

## 화면 반영

- 기본 기획안 입력값을 `강남 미디어 윈터페스타`로 변경했다.
- 행사장 주소, 기간, 프로그램, 시설명, 예산, 키워드를 강남 도심 미디어아트 축제 맥락에 맞췄다.
- 입력 패널 상단에 `TourAPI 실제 예시` 안내를 추가해 심사자가 공공데이터 기반 예시임을 바로 확인할 수 있게 했다.
- 비개인 소셜 트렌드 샘플은 `미디어아트`, `겨울축제`, `빛축제`, `강남`, `가족` 키워드로 정렬했다.

## 한계

TourAPI는 축제별 실제 방문객 통계나 실시간 군중 데이터를 제공하지 않는다. 따라서 방문객 수와 수요 예측은 TourAPI 메타데이터, 관광데이터랩 유동인구, 주변 관광정보 형태, 비개인 트렌드 샘플, 사용자가 입력한 예산·수용 인원·프로그램 정보를 조합한 추정 프록시다.
