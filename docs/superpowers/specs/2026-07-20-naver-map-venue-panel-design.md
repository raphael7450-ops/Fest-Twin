# 네이버 지도 행사장 패널 설계

## 목표

`강남 미디어 윈터페스타` 기본 데모가 실제 장소 기반 서비스처럼 보이도록 네이버 지도 JS API v3를 사용해 행사장 지도 패널을 추가한다.

## 접근 방식

첫 구현은 수요 예측 계산식이나 TourAPI 프록시를 변경하지 않는다. TourAPI에서 확인한 행사장 좌표를 기준으로 네이버 지도 화면을 표시하고, 삼성역 출입구·코엑스 동문·미디어월 관람 구역 같은 주요 지점을 마커 형태로 보여준다.

## 화면 구성

- 위치: `시간대별 수요 예측` 아래, `혼잡도 시뮬레이션` 위
- 제목: `실제 행사장 지도`
- 보조 문구: `TourAPI 좌표 + 네이버 지도 API`
- 지도 표시 성공 시:
  - 행사장 중심 지도
  - 행사장 마커
  - 주요 진입·관람 지점 마커
  - 지도 하단에 좌표·출처 설명
- 지도 키 미설정 또는 스크립트 로드 실패 시:
  - 같은 패널 위치에 fallback 안내 표시
  - 행사장 주소, 좌표, 주요 지점 목록을 텍스트로 표시

## 데이터와 보안

- 네이버 지도 API 키는 `VITE_NAVER_MAP_NCP_KEY_ID` 환경변수로만 읽는다.
- GitHub, 문서, 테스트에는 실제 키를 기록하지 않는다.
- 브라우저에서 필요한 공개 지도 Client ID만 사용하며, 서버 비밀키 형태의 인증값은 사용하지 않는다.
- TourAPI 좌표는 `강남 미디어 윈터페스타` 조회 결과인 `127.0610512042`, `37.5103955843`를 기본값으로 둔다.

## 에러 처리

- 환경변수가 없으면 스크립트 요청을 하지 않고 fallback UI를 표시한다.
- 스크립트가 실패하면 fallback UI로 전환한다.
- 지도 SDK가 이미 로드되어 있으면 중복 스크립트 삽입 없이 기존 객체를 사용한다.

## 테스트

- 앱 렌더 테스트에서 `실제 행사장 지도`, `네이버 지도 API 키 미설정`, `강남 미디어 윈터페스타`가 보이는지 확인한다.
- 지도 키가 없는 테스트 환경에서도 앱이 오류 없이 렌더링되어야 한다.
- 빌드에서 `window.naver` 타입 정의가 깨지지 않아야 한다.

## 후속 확장

- 네이버 지오코딩으로 주소-좌표 교차 검증
- 주변 POI와 대중교통 접근성 점수화
- 길찾기 API 기반 진입 동선 혼잡 리스크 보정
